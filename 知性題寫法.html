知性題寫法

小題一的答題要點、小題二的四段式，以及知性題四型的基本寫法、進階技巧與填空模板。

知性題的高分公式是「讀得準＋例子對＋想得深」。評分原則中 A+ 與 A 的差別，幾乎都在「結構嚴謹、具說服力、層次井然」。模板負責結構，你的例子負責說服力。

  • 2小題二通則

  • 4知 B 現象分析

小題一

約 4 分：讀得準，比寫得漂亮重要

寫法
  • 只用文本的資訊回答，不加自己的意見。
  • 題目問幾點就寫幾點：「兩個錯誤」就寫「其一……其二……」。
  • 抽出文本的關鍵字。參考試卷中沒寫到「網頁連結」的答案至多 2 分。
  • 嚴守字數與行數上限。
模板
小題一句型空格可直接填寫，自動儲存
  1. 問「是什麼」：「依文意，是指，其目的在於。」
  2. 問「兩點／正負」：「其一，；其二，。」或「正面而言，；負面而言，。」
  3. 問「原因」：「因為（文本證據），所以。」
小題二通則

約 21 分：立論、舉例、分析、收束

基本四段式
  1. 立論：第一句就回答題目，不用名言或故事開頭繞圈。
  2. 舉例：一個自己的具體經驗（人、時、地、一句對話），3–4 句就夠。
  3. 分析：用題目的概念解釋例子——「這就是文中所說的……，因為……」。
  4. 收束與延伸：回到立場，再往前推一步（對社會、對未來的自己意味著什麼）。
進階通則
  • 一個例子挖深，勝過三個例子平鋪。例子後面接「這讓我發現……」，不要接下一個例子。
  • 層遞：個人 → 群體 → 社會，或現象 → 原因 → 對策；用「更進一步來看」「另一方面」轉接。
  • 立論要有自己的詞：例如把「標籤」重新定義為「暫時的捷徑」。好的自創詞就是評分原則說的「詮釋深刻」。
  • 小題二也要連回文本：112 就有考生只寫自己、忘了連結文本，導致回答不完整。
知 A　立場二擇一

選邊站，但先承認對方有道理

歷屆例題

110 學測：「經驗機器」可以讓人體驗任何想要的人生，你支持接上這台機器嗎？／參考試卷：你贊成或反對推行「被遺忘權」？

基本（保住 B+）

明確選一邊，給兩個理由，各配一個例子。

進階（衝 A / A+）

讓步後立論：「誠然……然而……」，先承認對方的合理處，再說明自己為何仍選這邊；或提出「在什麼條件下」我會改變立場。這會讓文章從「意見」升級成「判斷」。

答題模板
知 A 模板空格可直接填寫，自動儲存
  1. 表態：「面對與兩種選擇，我傾向，因為我相信。」15%
  2. 理由一＋例子：「首先，。以我自己為例，。這說明。」30%
  3. 讓步＋理由二：「誠然，；然而，，因此。」30%
  4. 收束：「選擇，並不是否定，而是。若，我也願意。」25%
知 B　現象分析

把正負寫成一條光譜，而不是兩個框

歷屆例題

113 學測：標籤用在人身上有正面與負面作用，請以貼標籤或被貼標籤的實例說明你的看法。／114 學測：「擬社會互動」可能帶來哪些正負面影響？

基本（保住 B+）

正面一段、負面一段、看法一段，每段一個例子。

進階（衝 A / A+）

找到轉換點：同一個標籤什麼時候從助力變成枷鎖？把「正負」寫成一條光譜，指出分界在哪裡，最後提出「怎麼讓正面大於負面」。

答題模板
知 B 模板空格可直接填寫，自動儲存
  1. 定義現象：「是一種的現象，它本身沒有好壞，關鍵在於。」15%
  2. 正面作用＋例子：「當時，它能。例如。」25%
  3. 負面作用＋例子：「但當時，它便成為。我曾經。」25%
  4. 轉換點與對策：「正負之間的分界在於。因此，我們應該，讓大於。」35%
知 C　概念應用

用題目的概念當放大鏡，重新看自己

歷屆例題

115 學測：女主角因為和小豬「對到臉」而不忍吃牠。請舉出生活中選擇逃避或積極承擔的事例，就如何做出選擇表達看法與省思。

基本（保住 B+）

用自己的話重述概念，再套一個例子。

進階（衝 A / A+）

反向省思：不只寫「我曾經承擔」，也寫「我曾經逃避，以及為什麼」。誠實的自我檢討最有說服力，也最符合「省思」這個任務動詞。

答題模板
知 C 模板空格可直接填寫，自動儲存
  1. 重述概念：「文中所謂，指的是。」15%
  2. 我的事例：「這讓我想起。當時我選擇了（逃避／承擔）。」30%
  3. 用概念解釋事例：「用的角度來看，我之所以，是因為。」30%
  4. 反省與選擇：「如今回看，。我認為做選擇時應該，因為。」25%
知 D　圖表判讀

說出圖表沒說的事

歷屆例題

111 學測：依據「樂齡出遊」相關圖表，探究長者出遊的意義，以及如何照顧他們的身心需求。

基本（保住 B+）

引用圖表中最大、最小、變化最多的數字。

進階（衝 A / A+）

說出圖表沒說的：數據的限制、誰被忽略了，再提具體可行的建議（誰、做什麼、怎麼做）。

答題模板
知 D 模板空格可直接填寫，自動儲存
  1. 讀數據：「由圖表可知，最高／最低，的變化最明顯。」（引用具體數字）20%
  2. 解釋原因：「這反映了，可能是因為。」25%
  3. 觀察補充：「然而圖表沒有呈現的是。從我身邊的來看，。」25%
  4. 具體建議：「因此，我建議、，才能。」30%

收進工具箱：知性題

四型的差別在「小題二要你做什麼」：選邊、分析兩面、應用概念、解讀數據。

題型核心任務進階一招
知 A　立場二擇一表態並說理讓步後立論：誠然……然而……
知 B　現象分析正負兩面＋看法找轉換點，寫成光譜
知 C　概念應用用概念解釋經驗反向省思：寫自己逃避的時候
知 D　圖表判讀讀數據＋建議說出圖表沒呈現的

練習題：寫出立論句與骨架

不用寫全文，只寫第一句立論與四段各一行。答案是參考思路，不是標準答案。

1知 A

有人認為高中應取消制服，讓學生自由穿著；也有人認為制服有其價值。你贊成哪一方？請寫出立論句與讓步句。

參考答案

立論：「我贊成保留制服，因為它讓學生在校園裡少一件需要比較的事。」

讓步：「誠然，自由穿著能表現個性；然而個性更該展現在想法與作品上，而不是衣服的價格。」

2知 B

「網路評分」（如餐廳星等）對消費者的正負影響為何？請寫出四段骨架。

參考答案
  • 定義：評分是把眾人經驗壓縮成一個數字。
  • 正面：降低踩雷風險，例如第一次去陌生城市找餐廳。
  • 負面：數字取代判斷，小店因幾則負評被埋沒。
  • 轉換點：當我們只看數字不看評論內容時，助力就變成偏見；對策是讀評論、留真實評價。
3知 C

承 115 題「臉」的概念：寫出一個你「選擇逃避」的事例，並用「臉」的概念解釋為什麼。

參考答案

參考：看到同學在群組被嘲笑時沒有出聲。用「臉」的概念解釋：螢幕上的他只是一個暱稱，我沒有「看見他的臉」，所以沉默不會讓我不安；直到隔天在教室看到他的表情，才感到愧疚。
