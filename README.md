# 國文學習地圖｜筱葳學測國文

準備 116 學年度學測（2027 年 1 月）國文考科的互動學習網站，包含國寫（國語文寫作能力測驗）與國綜（國語文綜合能力測驗）。

網站：https://yijenfeng.github.io/Chinese-Writing-Section-of-the-GSAT-2027/

## 修改國綜單元

單元 10–20 由 `tools/` 裡的 Python 檔產生。改完內容後在 repo 根目錄執行：

```
python3 tools/build_guozong.py
```

題數有增減時，記得同步修改 `index.html` 的題數與 `app.js` 的 `GZ_RE`。

## 填寫的資料存在哪裡

所有填寫內容都只存在使用者自己瀏覽器的 localStorage，不會上傳到任何地方。換裝置前，在首頁按「匯出備份」，到新裝置再「匯入備份」。

## 發布

Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`。
