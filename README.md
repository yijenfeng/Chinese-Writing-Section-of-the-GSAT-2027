# 國寫學習地圖｜筱葳學測國文

準備 116 學年度學測（2027 年 1 月）國語文寫作能力測驗的互動學習網站。

網站：https://yijenfeng.github.io/Chinese-Writing-Section-of-the-GSAT-2027/

## 內容

| 單元 | 檔案 | 可以做什麼 |
| --- | --- | --- |
| 首頁 | `index.html` | 學習地圖、我的進度、匯出／匯入備份 |
| 1 考試規格與歷屆題目 | `考試規格與歷屆題目.html` | 107–115 歷屆題目、參考試卷、命題趨勢 |
| 2 看題判斷題型 | `看題判斷題型.html` | 三步驟審題、八種題型判斷表、題型判斷測驗 |
| 3 知性題寫法 | `知性題寫法.html` | 四型寫法，模板空格可直接填寫 |
| 4 情意題寫法 | `情意題寫法.html` | 四型寫法，模板空格可直接填寫 |
| 5 經驗素材庫 | `經驗素材庫.html` | 12 張素材卡表單、完成度、下載文字檔 |
| 6 知性素材庫 | `知性素材庫.html` | 八個常見議題的正反論點、35 個名言／歷史／時事／研究素材，可依議題篩選 |
| 7 素材套用示範 | `素材套用示範.html` | 一個素材改寫成多個歷屆題目 |
| 8 練習計畫 | `練習計畫.html` | 階段勾選、自我檢查表、每日破題句、練習紀錄 |

## 填寫的資料存在哪裡

所有填寫內容都只存在使用者自己瀏覽器的 localStorage，不會上傳到任何地方。換裝置前，在首頁按「匯出備份」，到新裝置再「匯入備份」。

## 發布

Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`。
