看題判斷題型

三步驟審題流程與八種題型判斷表，拿到題目 3 分鐘內決定要用哪一套寫法。

寫得好的前提是寫得對。很多 B 級文章不是文筆不好，而是漏了題目的某個任務，或把情意題寫成了記敘流水帳。這個單元訓練「先判斷，再下筆」。

三步驟審題

拿到題目先不要動筆，花 3 分鐘做完三步

第 1 步：圈任務動詞

題幹最後的「請……」句裡，圈出說明、分析、比較、表明立場、舉例、省思、描寫、回應等動詞。每個動詞都是一個評分項目，少一個就降一級。

第 2 步：找對立或核心詞

知性題找文本裡的兩方（正／負、逃避／承擔、福爾摩斯／華生）。情意題找題目的意象（縫隙、冰箱），並問自己：「它在人身上是什麼？」

第 3 步：對照判斷表歸型

用下一節的判斷表找到題型，再翻到「知性題寫法」或「情意題寫法」的對應模板。

判法

115 情意題同時有意象（幾米的圖）與關係（隔閡）。題幹要求「陳述原因、換位思考、傳達回應」，這些都是關係事件的任務，所以主模板用情 丙，意象只在開頭與結尾當引子。

1判斷題型自編練習題：非歷屆試題，也非大考中心練習題

近年「躺平」一詞在年輕人之間流行。請說明此現象可能帶來的正面與負面意義，並提出你的看法。

訊號是「正面與負面」。正、負各一段，各配一個例子，最後找出兩者的分界點。

參考答案

本站自編參考答案，非大考中心公布的參考答案或佳作，只示範一種寫法。

題型：知 B　現象分析

審題：任務動詞是「說明」正面與負面意義、「提出看法」。三個任務都要寫到，看法要獨立成段。

立論／破題：「躺平不是放棄人生，而是對過度競爭按下暫停；危險在於，暫停變成了停止。」

段落骨架：

  1. 定義現象：躺平是年輕人面對升學、工作的高壓，主動降低追求的態度，它本身沒有好壞。
  2. 正面意義：拒絕只用分數與薪水衡量自己，保護身心。例如同學退掉第五個補習科目，換回睡眠和畫畫的時間。
  3. 負面意義：當躺平成為逃避的藉口，就失去改變處境的動力。例如我曾以「躺平」為由不參加科展，事後才發現錯過了真正想做的題目。
  4. 轉換點與看法：正負的分界在於「躺下之後，還有沒有想走的方向」。

示範段落：

躺平的正負，不在躺下的姿勢，而在躺下之後眼睛看向哪裡。若是為了看清自己想要什麼而暫停，那是一種清醒；若只是因為害怕失敗而不再起身，那就是另一種形式的逃避。對我而言，值得學的不是躺平，而是在疲憊時允許自己停下，同時記得重新出發的方向。

2判斷題型自編練習題：非歷屆試題，也非大考中心練習題

請以〈如果時間可以收藏〉為題，寫一篇文章。

題目是一個抽象物。先定義「對我而言，可以收藏的時間是……」，再用一件事證明。

參考答案

本站自編參考答案，非大考中心公布的參考答案或佳作，只示範一種寫法。

題型：情 甲　意象轉化

審題：題目是一個抽象的「可以收藏的時間」，沒有指定事件。要先定義「收藏」在你身上的意義，再用一件事證明。

立論／破題：「如果時間可以收藏，我想收的不是假期，而是外婆削蘋果時，果皮一圈一圈不斷的那十分鐘。」

段落骨架：

  1. 定義意象：收藏是把不會再來的東西留下來；收藏時間，就是收藏某個人陪在身邊的樣子。
  2. 意象的特性：收藏品要挑選、要保存，也會被反覆拿出來看。
  3. 經驗場景：外婆坐在藤椅上削蘋果，刀聲細細的，果皮垂到地上都不斷。她說：「皮斷了，就不甜了。」
  4. 翻轉：原以為收藏時間是把那十分鐘鎖起來；外婆住院後才明白，時間收不住，能收藏的是她留在我身上的習慣。
  5. 呼應收尾：現在換我削蘋果給弟弟，果皮還是常常斷，但我一直在練。

示範段落：

外婆住院那年，我才知道時間收不住。那十分鐘再也回不來，可是每當我拿起水果刀，手腕就會不自覺地轉成她的角度。原來時間不是被鎖在盒子裡收藏的，而是被另一個人接住，繼續轉下去。

示範用的是假設情境，請換成你素材卡 #3（長輩教你的一件小事）或 #8（讓你想起某人的氣味）的真實經驗。

3判斷題型自編練習題：非歷屆試題，也非大考中心練習題

下圖為近十年高中生每日使用手機時數的變化。請說明圖表呈現的趨勢，並提出你認為合宜的使用建議。

有圖表、要你說明趨勢與建議。先引用最大、最小或變化最明顯的數字，再解釋原因、提出具體建議。

參考答案

本站自編參考答案，非大考中心公布的參考答案或佳作，只示範一種寫法。

題型：知 D　圖表判讀

審題：有圖表、要「說明趨勢」並「提出建議」。先讀數據，再解釋原因，最後的建議要具體到能執行。

立論／破題：「手機使用時數逐年上升，問題不在「用多久」，而在「被誰決定用多久」。」

段落骨架：

  1. 讀數據：引用圖表的起點、終點與變化最大的年份（例如：假設由每日 2 小時增至 5 小時，以某一年增幅最大）。
  2. 解釋原因：線上課程、社群與短影音的普及，讓手機從工具變成生活的預設畫面。
  3. 觀察補充：圖表只呈現時數，沒有呈現用途；同樣三小時，查資料和滑短影音的影響完全不同。
  4. 具體建議：以「用途」而非「時數」管理；睡前一小時手機放客廳；關掉非必要通知。

示範段落：

因此，與其要求學生每天少用一小時，不如先讓他們知道時間花到哪裡。我自己的做法是每週日看一次手機的使用紀錄，把「查資料」和「滑影片」分開計算，並在睡前一小時把手機放在客廳充電。當選擇權回到自己手上，時數自然會下降。

這題的圖表是自編情境，題目並未提供實際數據；示範中的數字是假設，考試時一定要引用題目圖表的真實數字。

4判斷題型自編練習題：非歷屆試題，也非大考中心練習題

文章提出「斷捨離」的概念：捨棄不需要的物品以整理內心。請結合生活經驗，說明你如何理解並運用這個概念。

題幹先定義概念，再要你舉例。用概念重新解釋自己的經驗，最好包含一次「捨不得丟」的反向例子。

參考答案

本站自編參考答案，非大考中心公布的參考答案或佳作，只示範一種寫法。

題型：知 C　概念應用

審題：題幹先定義「斷捨離」，再要你「結合生活經驗」說明理解與運用。這是概念應用：用概念解釋經驗，並帶出省思。

立論／破題：「斷捨離教我的不是丟東西，而是分辨：哪些東西我需要，哪些只是我捨不得承認已經不需要。」

段落骨架：

  1. 重述概念：斷捨離是透過捨棄不需要的物品，整理生活與內心的方法。
  2. 我的事例：升高三整理書桌，我丟掉整箱國中講義，卻怎麼也丟不掉一本寫滿同學紙條的筆記本。
  3. 用概念解釋：講義只是工具，所以捨得；筆記本承載的是關係，它雖然不再有用，卻仍是我需要的。
  4. 反省與選擇：斷捨離的目的不是捨得越多越好，而是在丟與留之間，看清自己真正在乎什麼。

示範段落：

以斷捨離的角度來看，我之所以能毫不猶豫地丟掉講義，是因為它們只剩下「曾經有用」；而那本筆記本，我翻開時仍會笑出聲，它對現在的我仍然有作用。原來「捨不得丟」不一定是失敗，它反而像一面鏡子，照出我真正在乎的東西。

5判斷題型自編練習題：非歷屆試題，也非大考中心練習題

請以〈那一頓沒吃完的晚餐〉為題，寫你與某人之間的一段經歷與體會。

重點在「與某人之間」的變化，主模板用關係事件，晚餐場景只當開頭。

參考答案

本站自編參考答案，非大考中心公布的參考答案或佳作，只示範一種寫法。

題型：情 丙　關係事件

審題：重點是「你與某人之間」的經歷與體會，主結構用關係事件；「沒吃完的晚餐」是場景，也是全文的線索物件。

立論／破題：「那一碗湯在桌上放到冷，我和媽媽之間隔著的，從來不只是一張餐桌。」

段落骨架：

  1. 點出關係：我和媽媽之間曾經隔著一場關於選組的爭吵。
  2. 衝突：晚餐時話題轉到選組，她說「讀設計會餓死」，我放下筷子回房間，湯一口也沒喝。
  3. 換位思考：後來才想到，她說那句話時，想的是自己年輕時找不到工作的那幾年。
  4. 轉折與回應：隔天桌上又是同一鍋湯，旁邊多了一份她印的設計系簡章。
  5. 未完的體悟：我們仍然會吵，但我學會在放下筷子之前，先把她的話聽完。

示範段落：

後來我才想到，媽媽說「會餓死」的時候，聲音其實在發抖。那不是對我的否定，而是她把自己年輕時找不到工作的害怕，原封不動地遞給了我。那一頓沒吃完的晚餐，冷掉的不是湯，而是兩個都太怕對方受傷的人，同時選擇了沉默。

示範用的是假設情境，請換成你素材卡 #1（與家人最難忘的一次衝突）的真實經驗。

6判斷題型自編練習題：非歷屆試題，也非大考中心練習題

有人主張高中應取消段考排名，也有人認為排名能激勵學習。你支持哪一方？請說明理由。

「支持哪一方」就是立場二擇一。記得用「誠然……然而……」先承認對方的合理處。

參考答案

本站自編參考答案，非大考中心公布的參考答案或佳作，只示範一種寫法。

題型：知 A　立場二擇一

審題：「你支持哪一方」就是立場二擇一。要明確表態，並用「誠然……然而……」處理對方的理由。

立論／破題：「我支持取消公開的段考排名，因為學習需要的是方向，而不是被放在一排數字裡比較。」

段落骨架：

  1. 表態：支持取消公開排名，但保留個人成績分析。
  2. 理由一＋例子：排名只告訴你「在誰前面」，沒告訴你「哪裡不會」。我曾因排名進步十名而鬆懈，下次卻在同一個單元重複失分。
  3. 讓步＋理由二：誠然，排名能帶來競爭的動力；然而這種動力常常建立在焦慮上，讓人只敢選擇有把握的科目。
  4. 收束：取消排名不是取消標準，而是把標準從「別人」換回「昨天的自己」。若學校能提供個人的弱點分析，我願意接受任何形式的評量。

示範段落：

誠然，排名能讓人知道自己的位置，也能帶來競爭的動力；然而，這種動力往往建立在焦慮之上。高一時我為了守住名次，只選有把握的題目練習，真正不會的單元反而一直沒有碰。因此，比起一個名次，學生更需要的是一張告訴他「哪裡還不會」的地圖。

立場選哪一邊都可以，評分看的是理由與論證，不是立場本身。

7判斷題型自編練習題：非歷屆試題，也非大考中心練習題

請以〈下雨天的味道〉為題，寫一段由氣味喚起的記憶與感受。

氣味＋記憶，與 112〈花草樹木的氣味記憶〉同型。關鍵在今昔對照，讓氣味和記憶綁得夠緊。

參考答案

本站自編參考答案，非大考中心公布的參考答案或佳作，只示範一種寫法。

題型：情 乙　感官與場景記憶

審題：氣味＋記憶，與 112〈花草樹木的氣味記憶〉同型。關鍵在感官細節要具體，並寫出今昔對照。

立論／破題：「下雨天的味道，是柏油路被打濕的那一刻，從地面浮上來的一股溫溫的土腥味。」

段落骨架：

  1. 感官特寫：雨剛落下時，柏油路冒出溫熱潮濕的土味，像整條街在嘆氣。
  2. 記憶展開：國小放學突然下大雨，爸爸騎機車來接我，雨衣裡混著他身上的機油味和雨的味道。
  3. 今昔對照：當時只覺得雨衣悶、很丟臉；現在才知道，那是他提早下班、騎了半個城市才換來的味道。
  4. 意義收束：下雨天的味道保存的不只是一場雨，還有一個人在雨裡朝我趕來的樣子。

示範段落：

那是一種溫溫的、帶著土腥的味道，像整條街在雨落下的瞬間一起嘆了一口氣。每當聞到它，我就回到國小三年級的校門口，看見爸爸的機車在雨幕裡亮著一盞黃燈。他掀開雨衣叫我鑽進去，裡面混著機油味和雨的味道，悶得我一路都不想說話。

示範用的是假設情境，請換成你素材卡 #8（讓你想起某人的氣味、聲音或食物）的真實經驗。

8判斷題型自編練習題：非歷屆試題，也非大考中心練習題

閱讀一段作家描寫父親背影的文字後：小題一分析作者為何流淚；小題二以「背影」為題寫自己的經驗。

先給作家文本、小題問人物情感，就是文本對讀。作文要借作家的手法（以一個畫面承載情感），而不只是寫父親。

參考答案

本站自編參考答案，非大考中心公布的參考答案或佳作，只示範一種寫法。

題型：情 丁　文本對讀

審題：先給作家文本，小題一問人物情感，小題二要你以同題寫自己，就是文本對讀。小題一要引文本證據；小題二要借作家的手法。

立論／破題：「（小題二破題）我記得最清楚的媽媽，不是她的臉，而是她每晚在補習班門口等我時，被路燈拉長的背影。」

段落骨架：

  1. 小題一：依文本找出作者流淚的直接原因（看見的畫面）與深層原因（對父愛的領悟或愧疚），兩層都要寫。

示範段落：

擬社會互動的正負，關鍵不在追不追星，而在是否記得這段關係是單向的。當我把直播主當成一面鏡子，看見自律的可能，它就是助力；當我開始期待他回應我的心事，甚至因為他的一句話影響心情，這段關係就從陪伴變成了依賴。真正的陪伴，最後仍要回到能互相回應的人身上。

  1. 〈辛夷塢〉的體會：辛夷花在無人的山澗旁「紛紛開且落」，不因為沒有人看見而不開。生命的價值在於自足地完成自己。
  2. 〈幽谷〉的體會：谷中小草都在天亮前選好顏色開花，只有一株猶豫不決，最後只留下枯萎的花苞。生命有時限，遲遲不選擇，也是一種選擇。
  3. 我希望的生命過程：像幽谷中的小草一樣及時做出選擇，選定之後全力綻放。
  4. 我希望的生命結果：像辛夷花一樣，開與落都坦然，不以有沒有人欣賞來衡量自己。

示範段落：

如果我是一朵花，我不想成為那株在幽谷裡猶豫到最後的小草。我會在天亮之前選定一種顏色，也許不是最鮮豔的，但那是我自己選的。然後我想像山澗旁的辛夷花那樣，安靜地開，安靜地落。沒有人經過也沒關係，因為花開本身，就已經是答案。
